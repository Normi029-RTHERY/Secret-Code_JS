#Digicode Game
Ce projet est un jeu de digicode développé en JavaScript, HTML et CSS. Le but du jeu est de deviner un code secret en un nombre limité de tentatives et dans un temps imparti.

##Fonctionnalités
- Génération aléatoire d’un code secret
- Gestion du temps et des tentatives
- Calcul Affichage et sauvegarde du score
- Animations de la victoire
- Interface responsive

##Structure du projet
src/
  app.js
  index.html
  styles.css
  app/
    code.js
    GameController.js
    timer.js
  assets/
    favicon.ico
    fonts/
      ...

##Utilisation
- Cliquez sur "Démarrer" pour lancer une partie.
- Entrez le code dans le champ prévu.
- Le score est calculé en fonction du temps.
- Input via le keypad
